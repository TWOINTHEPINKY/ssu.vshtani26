# CyberSportsPortal API Tests

**Коллекция тестов для API киберспортивного портала**  
Выполнена в **Bruno** (VS Code) по спецификации OpenAPI. Федотов Данила СГУ.

## 📋 Описание
Коллекция покрывает **все 11 GET-эндпоинтов** тестового сервера, для каждого запроса добавлены:

- Минимум **2 ассерта** (проверка статуса и структуры ответа)  
- **JavaScript-тесты** для проверки полей в ответе  
- **Переменная окружения** `baseUrl` для быстрой смены хоста  
- Параметры фильтрации вынесены в **Query Params** (запрос `/api/Players/filter`)
