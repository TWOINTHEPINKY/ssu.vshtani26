## 📑 Описание
В этом разделе собраны мои **лабораторные, курсовые и практические работы**, выполненные за время обучения в университете. Здесь можно проследить мою эволюцию от базовых алгоритмов и консольных утилит до полноценных архитектурных решений, баз данных и командных проектов.

Основная цель репозитория — структурированное хранение академического кода, фиксация прогресса и демонстрация навыков решения сложных алгоритмических задач.

## 🛠 Технологии и дисциплины
В рамках учебной программы я изучаю и применяю широкий спектр инструментов:

* **Языки программирования:** C / C++, C#, Java, Python, SQL
* **Алгоритмы и структуры данных:** Сортировки, графы, деревья, ООП, паттерны проектирования
* **Базы данных:** PostgreSQL, MySQL, SQLite (проектирование, нормализация, сложные запросы)
* **Прочее:** Низкоуровневое программирование, архитектура ЭВМ, операционные системы, основы сетей

## 🚀 Как запустить и протестировать

1. Перейдите в папку нужного предмета или лабораторной:
   ```bash
   cd "Название_Предмета/Лабораторная_1"
   ```
2. Скомпилируйте или запустите код согласно спецификации (подробные инструкции по сборке, компиляторам или флагам находятся в `README` внутри папок конкретных предметов).

## 🏛 Чему меня учит академическая среда
* **Фундаментальной базе:** Пониманию того, как код работает «под капотом» (память, указатели, потоки).
* **Математической логике:** Проектированию оптимальных алгоритмов с учетом вычислительной сложности O(n).
* **Дисциплине:** Написанию кода в строгом соответствии с ТЗ, ГОСТами (при оформлении документации) и жесткими дедлайнами сессий.
